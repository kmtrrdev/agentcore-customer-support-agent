# Project Reflection: AI Customer Support Agent with Amazon Bedrock AgentCore

## 1. Design Decision
A core architectural decision was adopting a modular, decoupled integration pattern that separates transactional actions from sandboxed arithmetic computation and conversational retrieval. Rather than granting the core LLM direct access to database tables or relying on non-deterministic generative arithmetic, we integrated Lambda functions through Amazon Bedrock AgentCore Gateway using the Model Context Protocol (MCP) over Streamable HTTP for order tracking and returns. Concurrently, complex loyalty point calculations were delegated to the AgentCore Code Interpreter. This separation of concerns ensures strict schema validation for sensitive customer operations while guaranteeing zero arithmetic hallucination during multi-tier discount and points redemption workflows.

## 2. Challenge Encountered
A primary technical challenge was managing asynchronous event loops and remote browser automation lifecycles within an ASGI application. When instantiating `AgentCoreBrowser` inside the `@app.entrypoint` asynchronous handler, the browser tool's default initialization instantiated an unstarted event loop on the current thread, disrupting AnyIO/Starlette task context and triggering weak reference type errors. We resolved this by explicitly capturing and restoring the running ASGI event loop during runtime initialization. Additionally, remote browser automation required strict multi-step execution sequencing (`init_session` -> `navigate` -> `evaluate` -> `close`). Providing deterministic prompt-level guidance alongside proper CDP WebSocket authentication allowed the agent to navigate external domains and extract web metadata accurately.

## 3. Production Consideration
Transitioning this agent to a high-volume production environment necessitates hardening security boundaries and operational observability. First, the AgentCore Gateway authorizer should migrate from the educational `NONE` setting to mutual AWS IAM SigV4 or OAuth2 token authorization to prevent unauthorized tool execution. Second, egress networking for the browser sandbox should enforce domain allowlisting via enterprise proxy configurations. Finally, we enhanced observability by configuring CloudWatch Metric Filters on the AgentCore Runtime log streams paired with automated CloudWatch Alarms that alert engineers when error frequencies breach operational thresholds, enabling automated circuit breaking and graceful fallback to human customer service representatives.
